Steam Redesigned

An unofficial redesign of the Steam store and community, running on live Steam data. Use it as a Windows app, an Android app or right in your browser.

Download for Windows Get the Android app

Version 3.3.0 · Windows 10 and 11 · Android 7 and later · Free · Open the web version

A closer look

Every screen is rebuilt from scratch with new layouts, motion and colour, while keeping Steam's blue.

What it does

Store

  • Every Steam game with 100+ players at its daily peak, up to 10,000, refreshed automatically.
  • Official Windows, macOS, Linux and Steam Deck logos next to every game name.
  • Live player counts, price and player history charts, and the lowest recorded price.
  • Price alerts on your wishlist with Windows and Android notifications, side-by-side compare and a release calendar.
  • Search that forgives typos, plus AI search and price advice with a key from any AI provider (Gemini and Groq give free keys).

Recommendations

  • A taste profile built from what you like, wishlist, own and open.
  • Every pick explains why it's there.
  • "More like this" and "Not interested" re-rank the list instantly.
  • Hide tags or owned games from the whole store.

Community

  • Screenshots, art, videos, workshop items, guides, reviews, discussions and news.
  • Comment threads open in place with an animation.

Make it yours

  • Themes, colours, backgrounds, notifications and accessibility options.
  • Animation settings with a live preview: card hovers, page transitions, speed and more.
  • The app lives in the system tray, with an Update now button for instant refreshes.

Installing

  1. Run the file you downloaded.
  2. Windows may show "Windows protected your PC" because the app isn't code-signed yet. Choose More info, then Run anyway.
  3. Open Steam Redesigned from the Start menu or the Desktop. It lives in the system tray; quit it from the tray icon.
  4. To remove it, go to Windows Settings › Apps › Installed apps.

Check your download

Open Command Prompt in your Downloads folder and run:

certutil -hashfile Steam-Redesigned-Setup-3.3.0.exe SHA256

The result should match the checksum under the file above.

Installing

  1. Download the APK on your phone and open it from the notification or your Downloads.
  2. The app isn't from the Play Store, so Android asks first. Tap Settings, turn on Allow from this source for your browser, then go back.
  3. Tap Install. If Google Play Protect asks about an unknown app, choose More details, then Install anyway.
  4. Open Steam Redesigned from your home screen. To remove it, press and hold the icon and choose Uninstall.

Built to be safe to share

Every install is a fully independent copy. Nothing links it back to anyone else's computer or phone.

The Windows app

  • No remote control, no connection between copies and no hidden updates.
  • Its local data server only answers the PC it runs on. Other devices on the network can't reach it.
  • Refuses debugging switches, can't be turned into a script runner, and won't start if its files were modified.
  • Your AI provider key, if you add one, is encrypted with your Windows account.

The Android app

  • The only permission it asks for is internet access: no camera, contacts, location or storage.
  • Talks only to this project's read-only service and Steam's image servers, always over HTTPS.
  • No account and no tracking; app backups are turned off, so your data stays on the phone.
  • Signed with the Project Vanguard key, so nobody else can publish an update to it.

The website

  • Read-only: settings and keys only exist in the desktop app.
  • Strict content security policy, HTTPS only, no framing and no tracking.
  • Requests from other websites are refused, and every endpoint is rate-limited.
